# Журнал изменений

Формат: новые записи сверху. В каждой записи — дата, версия/этап и список изменений с файлами,
чтобы при поиске бага было видно, где и когда он мог появиться.
Подробная история — в git (`git log -p -- <файл>`).

## [0.3.0] — 2026-10-19 — Этап 3: серверный мессенджер

### Дизайн
- Попробован стиль Minecraft (кнопки игры, предметы в слотах, обои из блоков) — отклонён, возвращён прежний дизайн.
  Вариант сохранён в `git stash` («Minecraft-style redesign»).

### Протокол (common)
- `PROTOCOL_VERSION = 2`. Пакеты мессенджера `MessengerPackets` (id 2–22) и данные `MessengerData`.
- `PacketWriter/Reader`: UUID, списки с лимитом, необязательные значения, строки с лимитом длины.

### Сервер (common/server)
- `BlockPhoneServer` — общий фасад для всех платформ (рукопожатие, игроки с модом, передача мессенджеру).
- `MessengerService` + `MessengerRepository` + `Database`: личные и групповые чаты, история по страницам, правка и удаление своих
  сообщений, непрочитанные, поиск игроков, «печатает», статус в сети, лимит частоты, группы (переименование владельцем,
  добавление, исключение, выход с передачей владения).
- Хранилище: H2 (файл, по умолчанию) или MySQL/MariaDB.
- Тесты `MessengerServiceTest` (6 сценариев) — проходят.

### Платформы
- Fabric: `FabricServerHandler` переведён на `BlockPhoneServer`; в мод встроены H2 и MariaDB (+3,3 МБ); настройки хранилища в server.json.
  **Исправлено:** приветствие сервера терялось (в событии JOIN игрок ещё не в списке игроков).
- Paper: переведён на `BlockPhoneServer`; драйверы по `libraries:`; настройки хранилища в config.yml; приветствие и при входе.
- Новый модуль `velocity` — плагин для прокси: мессенджер общий для всей сети серверов.

### Клиент
- Приложение «Мессенджер» (видно только на сервере с BlockPhone): список чатов, новый чат (поиск игроков), создание группы,
  переписка (пузыри, дни, подгрузка истории, мгновенный показ отправленного, Enter/Shift+Enter, меню по ПКМ: изменить/копировать/удалить),
  информация о чате (участники, переименовать, добавить, исключить, покинуть).
- Уведомления о новых сообщениях (тост в углу экрана), значок непрочитанных на иконке, аватары-лица скинов.
- `DevShots`: сценарий `BLOCKPHONE_DEV_SCENARIO=messenger` + `BLOCKPHONE_DEV_MESSENGER=1`.

### Проверено
- `./gradlew build` (fabric, paper, velocity), тесты common.
- В одиночной игре с dev-флагом: рукопожатие, список чатов, переписка, отправка, группа, инфо, новый чат, тёмная тема, тост, значок.

### Не проверено (нужен ручной тест)
- Настоящий выделенный Fabric-сервер, Paper и Velocity с несколькими игроками; MySQL.

## [0.2.0] — 2026-10-19 — Этап 2: заметки, камера, галерея

### Общий UI
- `ui/TextArea` — поле ввода текста (многострочное, перенос, выделение, буфер обмена, прокрутка).
- `PhoneDialog` + `PhoneScreen.showDialog` — диалоги подтверждения; кнопка действия справа в заголовке
  (`PhoneApp.headerAction/onHeaderAction`); `PhoneScreen.closeImmediately`.
- `PhoneDraw.wrapped/wrappedHeight/button`.
- `storage/ClientFiles` — папка данных `<игра>/blockphone/` и фоновый поток `IO`.

### Заметки (`apps/notes`)
- Список с поиском, создание «+», редактор (первая строка — заголовок), удаление с подтверждением.
- Хранение в `blockphone/notes.json` (атомарная запись), пустые заметки удаляются.

### Камера (`camera/`, `apps/camera`, `mixin/`)
- Полноэкранный видоискатель вместо HUD: рамка, фокус, сетка третей, нижняя панель параметров, подсказки.
- Параметры: ISO (AUTO, 100–6400), выдержка (AUTO, 1/1000–1"), экспокоррекция ±2, 10 фильтров, сетка, таймер 3/10 с; зум колесом до 10×
  (чувствительность мыши уменьшается с зумом).
- Фильтры — постэффект-шейдер `shaders/post/filter.fsh` + `post_effect/filter_*.json` (генерирует `tools/gen_filters.py`).
- Снимок без интерфейса и руки; длинная выдержка (от 1/15) копит кадры → смаз; экспозиция и шум применяются к файлу.
- Сохранение в `blockphone/gallery/IMG_*.png` + `.json` (`PhotoMeta`: время, сервер/мир, измерение, координаты, параметры).
- Управление: ЛКМ снимок, ПКМ следующий фильтр, ←→ параметр, ↑↓ значение, H панель, R сброс, G галерея, Esc выход.
- Новая клавиша «Камера (сразу)» (по умолчанию не назначена).
- Миксины: `GuiMixin`, `GameRendererMixin`, `GameRendererAccessor`, `MinecraftMixin`, `KeyboardHandlerMixin`, `MouseHandlerMixin`, `ToastManagerMixin`.

### Галерея (`apps/gallery`, `photo/`)
- Сетка миниатюр, просмотр со сведениями о снимке и листанием (←/→, колесо, стрелки), удаление с подтверждением, «Папка» (открыть в проводнике).
- Редактор: поворот, отражение, кадрирование (1:1, 4:3, 3:4, 16:9, 9:16), фильтр, яркость/контраст/насыщенность; «Как копию» или «Заменить».
- `ImageOps` (обработка на CPU), `PhotoStore`, `PhotoTextures` (кэш текстур с линейной фильтрацией).

### Dev
- `DevShots` теперь создаёт/загружает мир `blockphone_dev` и проверяет камеру, фото (в т.ч. длинную выдержку), галерею, редактор, заметки.
- `tools/gen_icons.py` дополнительно рисует текстуру шума `textures/gui/camera/noise.png`.

### Проверено (через DevShots)
- Миксины применяются, игра не падает; HUD, рука и тосты скрыты в камере; сепия и зум 2× в видоискателе.
- Фото сохраняются (обычное и 1/4 с на ISO 100 — светлее на ~3 ступени), сведения в JSON верные.
- Галерея: просмотр, сетка, редактор; заметки: список.

### Не проверено (нужен ручной тест)
- Реальное управление мышью и клавишами в камере, таймер, смаз при движении, редактирование и «Заменить», удаление, ввод текста в заметках.

## [0.1.0] — 2026-10-19 — Этап 1: каркас

### Проект
- Шаблоны `PhoneMod/` и `PhoneModPlugin/` заменены единым Gradle-проектом `BlockPhone` с модулями
  `common`, `fabric`, `paper` (`settings.gradle`, `build.gradle`, `*/build.gradle`). Старые папки не удалены, исключены из git.
- Gradle 9.8.0 (wrapper), демон Gradle на Java 25 (автоскачивание, `gradle/gradle-daemon-jvm.properties`).
- Маппинги переведены с Yarn на официальные Mojang.
- Mod id `blockphone`, пакет `dev.blockphone`.

### Протокол (common)
- Канал `blockphone:main`, формат «VarInt id + тело» (`Packets`, `PacketWriter`, `PacketReader`, `ProtocolException`).
- Пакеты `ServerHelloPacket` (S→C) и `ClientHelloPacket` (C→S). `PROTOCOL_VERSION = 1`.

### Сервер
- Fabric: `FabricServerHandler` — рукопожатие на выделенном сервере; конфиг `config/blockphone/server.json` (`FabricServerConfig`).
- Paper: `BlockPhonePaper` — то же через plugin messaging; `config.yml` (`messenger.enabled`, `phone-in-hand.visible`).

### Клиент
- Клавиша «Открыть телефон» (по умолчанию ↑), категория BlockPhone в настройках управления (`BlockPhoneClient`).
- Экран телефона `PhoneScreen`: корпус со скруглёнными углами, «островок» камеры, анимация выезда/закрытия,
  статус-бар (время, индикатор «связи» = есть ли BlockPhone на сервере, батарея), заголовок с кнопкой «назад»,
  полоска «домой». ESC — назад; клавиша телефона — закрыть. Игра не ставится на паузу.
- Каркас приложений: `PhoneApp`, `AppRegistry`, `PhoneState`, `PhoneDraw`, `PhoneTheme`, `PhoneLayout`, `PhoneClock`.
- Рабочий стол `HomeApp`: большие часы, дата, сетка иконок.
- Приложения: Калькулятор (`Calculator`, `CalculatorApp`, ввод мышью и с клавиатуры), Погода (`WeatherApp`: биом,
  осадки, «температура», игровое время, день, фаза луны, высота), Настройки (`SettingsApp`: язык, часы реальные/игровые,
  12/24ч, тема, обои, анимации, информация о версии/сервере/клавише).
- Заглушки «скоро»: Мессенджер (виден только на сервере с BlockPhone), Telegram, Камера, Галерея, Музыка, Заметки.
- Собственная локализация телефона `PhoneLang` (ru_ru / en_us, выбор в настройках); настройки игрока `PhoneSettings`
  (`config/blockphone/settings.json`).
- Иконки приложений и погоды генерируются `tools/gen_icons.py`.
- Dev-инструмент `DevShots` (переменная `BLOCKPHONE_DEV_SHOTS`) — автоскриншоты интерфейса.
- Погода вне мира (главное меню) показывает подсказку «Войдите в мир…» вместо пустого экрана.

### Проверено
- Сборка `./gradlew build` (fabric + paper).
- Клиент запускается, мод загружается без ошибок; через `DevShots` проверены рабочий стол, калькулятор,
  настройки и заглушки в светлой (EN) и тёмной (RU) теме.

### Не проверено (нужен ручной тест)
- Погода внутри мира, клавиша ↑ в игре, анимации.
- Рукопожатие с сервером: Paper-плагин и Fabric-сервер (иконка «Мессенджер» должна появиться, деления «связи» — полные).
