# Свои приложения для BlockPhone

Эта инструкция — для тех, кто хочет сделать своё приложение для телефона BlockPhone: игрока, админа сервера,
независимого автора. Есть два способа:

* **Страницы в JSON** — программировать не нужно: приложение — один текстовый файл с экранами и кнопками.
* **Скрипт на Lua** — для всего остального: игры (свои экраны, меню, физика, управление клавишами), приложения со
  своим сайтом или API, игры по сети с друзьями на сервере («Дурак онлайн», крестики-нолики…), экран набок.
  См. [Скрипты (Lua)](#скрипты-lua).

> **Если приложение пишет нейросеть (ChatGPT, Claude и т. п.) — сначала спросите автора.**
> Нейросеть, которая делает приложение по этой инструкции, **обязана до создания `app.json` спросить у игрока его ник
> (или имя автора) и записать его в поле `"author"`**. Нельзя ставить в `"author"` название нейросети, «AI», «Assistant»,

## Как это устроено

```
Игрок                                   Сервер (по желанию)
.minecraft/blockphone/apps/             plugins/BlockPhone/apps/        (Paper)
  bank/                                 config/blockphone/apps/         (Fabric)
    app.json   ← экраны и кнопки          bank.json  ← данные и действия
    icon.png   ← иконка 64×64             (или Java-обработчик из своего плагина)
```

* **Клиентская часть** (`app.json`) ставится игроку в папку игры `blockphone/apps/`. В ней описаны страницы,
  текст, поля ввода и кнопки. Приложение работает везде: в одиночной игре и на любом сервере.
* **Серверная часть** нужна, только если приложению нужны данные или действия сервера: баланс, перевод денег,
  список домов, магазин… Её кладёт админ сервера в папку `apps` BlockPhone на сервере (файл с тем же id).
* Приложение — **это не программа**, а описание экранов. Телефон показывает его и выполняет действия из короткого
  списка (перейти на страницу, сохранить значение, открыть ссылку, отправить команду, спросить сервер). Поэтому
  приложение не может навредить игроку или дать ему нечестное преимущество (см. «Разрешения и безопасность»).

Где папка игры: в лаунчере — «Открыть папку игры» (обычно `%appdata%\.minecraft`). Проще всего: телефон →
**Настройки → Свои приложения → Открыть папку приложений**. Там же видно, какие приложения загрузились, их
разрешения и ошибки. Перезапускать игру не нужно — телефон замечает новые файлы за пару секунд.

## Быстрый старт

1. Откройте телефон → **Настройки → Свои приложения → Открыть папку приложений**.
2. Создайте там папку `hello`, а в ней файл `app.json` (в Блокноте: «Сохранить как», кодировка **UTF-8**):

```json
{
  "id": "hello",
  "name": "Привет",
  "color": "#4C8DF6",
  "pages": {
    "main": {
      "title": "Моё приложение",
      "elements": [
        {"type": "text", "text": "Привет, {player}!", "size": "large"},
        {"type": "text", "text": "Сейчас {time}", "color": "secondary"},
        {"type": "button", "label": "Ещё страница", "style": "primary", "action": {"open": "second"}}
      ]
    },
    "second": {
      "title": "Вторая",
      "elements": [
        {"type": "text", "text": "Это вторая страница."},
        {"type": "button", "label": "Назад", "action": {"back": true}}
      ]
    }
  }
}
```

3. Вернитесь на рабочий стол телефона — там появится «Привет».
4. Хотите иконку — положите рядом `icon.png` (квадрат, лучше 64×64, до 32 КБ). Без неё рисуется первая буква названия.

Ещё пример — `example-tapper.json.example` в той же папке (счётчик нажатий с сохранением). Переименуйте в
`example-tapper.json`, чтобы включить.

## Файл app.json

Приложение — папка `<имя>/` с `app.json` и `icon.png`, **или** просто файл `<имя>.json` (иконка — `<имя>.png` рядом).

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | нет (по умолчанию — имя папки/файла) | Латиница, цифры, `_`, `-`, до 32 символов. По нему сервер находит серверную часть и блокирует приложение. |
| `name` | нет | Название. Строка или перевод: `{"ru_ru": "Банк", "en_us": "Bank"}`. |
| `version`, `author` | нет | Показываются игроку в настройках и в «Магазине». `author` — ник настоящего автора (нейросеть должна спросить его у игрока, см. выше). |
| `category` | нет | Категория в «Магазине»: `games` (игры), `tools` (утилиты), `social` (общение), `media` (музыка и видео), `education`, `finance`, `server` (для серверов), `other` (по умолчанию). |
| `uid` | нет | Постоянный уникальный id приложения. Писать руками не нужно: телефон создаёт его при первой публикации в магазин и дописывает в `app.json`. Не меняйте его при обновлениях — по нему серверы разрешают и блокируют приложение. |
| `color` | нет | Цвет плитки: `#RRGGBB`. |
| `permissions` | нет | Что приложению можно: `storage`, `links`, `clipboard`, `commands`, `server`, `internet`, `multiplayer`. См. ниже. |
| `script` | нет | Главный файл Lua (`"main.lua"`) — тогда `pages` не обязательны. Только для приложения-папки. |
| `orientation` | нет | `portrait` (по умолчанию) или `landscape` — телефон повёрнут набок (скрипт может менять). |
| `fullscreen` | нет | `true` — без строки состояния, заголовка и навигации (игры). «Назад/домой» — у нижнего края. |
| `hosts` | нет | Сайты для `http` (нужно разрешение `internet`): `["api.example.com", "*.example.com"]`. |
| `start` | нет | Первая страница (по умолчанию — первая в `pages`). |
| `order` | нет | Место на рабочем столе (меньше — раньше, по умолчанию 100). |
| `pages` | **да** | Страницы: `"id страницы": {"title": ..., "server": true/false, "elements": [...]}`. |

Любой текст можно писать с переводом: `{"ru_ru": "Перевод", "en_us": "Transfer"}` — телефон выберет язык игрока.

## Элементы страницы

Каждый элемент — объект с полем `type`. У любого элемента можно указать условие показа:
`"if": "{переменная}"` — показывать, только если значение не пустое и не `0`/`false`; `"unless"` — наоборот.

| type | Поля | Как выглядит |
|---|---|---|
| `text` | `text`, `size` (`small`, `normal`, `large`, `huge`), `color`, `align` (`left`, `center`, `right`) | Текст с переносом строк. `\n` — новая строка. |
| `title` | `text`, `color`, `align` | Крупный заголовок. |
| `card` | `elements: [...]` | Карточка-подложка с элементами внутри. |
| `row` | `label`, `value`, `color`, `action` | Строка «название … значение» (как в настройках). |
| `button` | `label`, `style` (`normal`, `primary`, `danger`), `action` | Кнопка во всю ширину. |
| `buttons` | `items: [кнопки]` | Несколько кнопок в ряд. |
| `input` | `id`, `label`, `placeholder`, `value`, `kind` (`text`, `number`, `player`), `required`, `min`, `max` | Поле ввода. Значение доступно действиям как `{id}`. |
| `list` | `items: [{title, subtitle, value, color, action, if}]` | Список строк на карточке. |
| `progress` | `label`, `value`, `max` (по умолчанию 100), `color` | Полоска прогресса. |
| `divider` | — | Разделительная линия. |
| `spacer` | `height` | Пустое место. |

Цвета (`color`): `accent` (акцентный цвет телефона игрока), `secondary`, `danger`, `success`, `text` или `#RRGGBB`.

Поля ввода проверяются до действия: `required` — нельзя оставить пустым; `kind: "number"` — только число (`min`,
`max` — границы); `kind: "player"` — ник игрока; для текста `max` — наибольшая длина.

## Переменные

В любом тексте можно писать `{имя}` — телефон подставит значение. `{имя|запасное}` — если значения нет.

| Переменная | Значение |
|---|---|
| `{player}` | ник игрока |
| `{lang}` | язык телефона (`ru_ru`, `en_us`) |
| `{time}`, `{date}` | время и дата |
| свои | значения, сохранённые действиями `set` / `add` (нужно разрешение `storage`) |
| от сервера | переменные серверной части (страница с `"server": true`) |
| `{id поля}` | в действиях — то, что игрок ввёл в поле |

Других данных у приложения нет — это сделано специально (см. «Безопасность»).

## Действия

Действие — поле `action` у `button`, `row` или строки `list`. В одном действии можно сочетать несколько пунктов,
они выполняются по порядку: сохранить → команда → сервер → сообщение → переход.

| Пункт | Разрешение | Что делает |
|---|---|---|
| `"open": "страница"` | — | Открыть страницу («назад» вернёт на текущую). |
| `"back": true` | — | Назад. |
| `"refresh": true` | — | Обновить данные сервера на странице. |
| `"close": true` | — | Выйти на рабочий стол. |
| `"toast": "текст"` | — | Сообщение внизу экрана. |
| `"confirm": "текст"` | — | Сначала спросить игрока «Выполнить?». |
| `"then": "страница"` | — | Куда перейти после выполнения (`back`, `refresh`, `close` или id страницы). |
| `"set": {"имя": "значение"}` | `storage` | Сохранить значения (можно с `{переменными}` и `{полями}`). |
| `"add": {"имя": 1}` | `storage` | Прибавить число (отрицательное — отнять). |
| `"copy": "текст"` | `clipboard` | Скопировать текст в буфер обмена. |
| `"url": "https://..."` | `links` | Открыть ссылку в браузере — **после подтверждения игрока**. Только http(s). |
| `"command": "spawn"` / `"commands": [...]` | `commands` | Отправить команду от имени игрока — **игрок видит её текст и подтверждает каждый раз**. Не чаще раза в секунду. |
| `"server": "функция"` | `server` | Вызвать функцию серверной части (поля страницы уходят на сервер). |

Пример — сохранить заметку из поля:

```json
{"type": "input", "id": "note", "label": "Заметка"},
{"type": "button", "label": "Сохранить", "action": {"set": {"my_note": "{note}"}, "toast": "Сохранено"}},
{"type": "text", "text": "Сохранено: {my_note|ничего}"}
```

## Разрешения и безопасность

Приложение обязано заранее перечислить разрешения в `"permissions"`. Если действие требует разрешение, которого
нет в списке, приложение **не загрузится** (ошибка видна в «Настройки → Свои приложения»). Игрок видит список
разрешений каждого приложения там же.

| Разрешение | Что даёт | Ограничения |
|---|---|---|
| `storage` | `set` / `add` — своё хранилище | только своё: файл `blockphone/appdata/<id>.json`, до 200 значений, до 64 КБ |
| `links` | `url` | только http(s), игрок подтверждает каждую ссылку |
| `clipboard` | `copy` | только запись; читать буфер обмена нельзя |
| `commands` | `command` | от имени игрока (его права), игрок видит текст и подтверждает; не чаще 1 раза в секунду |
| `server` | страницы с `"server": true`, `"server": "функция"`; в скрипте `server.call/vars` | только со своей серверной частью на текущем сервере |
| `internet` | скрипт: `http.get/post` | только сайты из `"hosts"`; без cookies, перенаправлений и данных игрока; до 60 запросов в минуту, ответ до 1 МБ; адреса этого компьютера и домашней сети (localhost, 127.*, 192.168.*, 10.*, 172.16–31.*, роутер) запрещены, даже если указаны в `"hosts"` |
| `multiplayer` | скрипт: `net.send/broadcast/players` | сообщения только этому же приложению у других игроков (на этом сервере или в комнате по коду); до 8 КБ; через плагин — до 40 за 5 с, через облако — до 100; `"relay"` — свой сервер комнат |
| `browser` | скрипт: `web.*` — настоящий браузер (Chromium) | любые сайты; профиль cookies — общий для приложений с этим разрешением; данных телефона браузеру не видно |
| `background` | скрипт: работать в фоне — запускается вместе с игрой, не закрывается при смене мира и сервера, `onTick` идёт всегда | рисования без открытого телефона нет |
| `notifications` | скрипт: `notify(…)` — уведомления телефона | не больше 20 в минуту; игрок может выключить уведомления приложения |
| `photos` | скрипт: `photos.pick` — фото, которое игрок **сам выбрал** в галерее; показать и отправить на свой сайт (`http.upload`) | всю галерею приложение не видит |
| `microphone` | скрипт: `mic.*` — запись голоса | пока идёт запись, телефон показывает значок «REC»; приложение свернули — запись прекращается |
| `display` | скрипт: `display.*` — «режим экрана»: картинка приложения на экране в мире, джойстик | только свои экраны игрока или экраны, к которым он сам подключился; видят картинку те, у кого приложение подключено (остальные — заставку с названием) |

**Чего у приложения нет никогда, ни с какими разрешениями:**

* доступа к файлам компьютера (кроме своего хранилища), к паролям, токенам и аккаунтам (Яндекс Музыка, Spotify,
  Telegram);
* доступа к переписке мессенджера, ленте, фото галереи, заметкам, музыке, Telegram;
* доступа к миру: блокам, сущностям, игрокам рядом, координатам, инвентарю. Поэтому приложение не может быть
  читом (xray, радар игроков и т. п.);
* команд и ссылок без подтверждения игрока (и в скриптах тоже: `runCommand`/`openUrl` спрашивают каждый раз);
* у скрипта — ни Java, ни файлов, ни `io`/`os`/`load`/`debug`: только Lua-песочница и API телефона ниже. Каждый вызов
  скрипта ограничен по числу шагов: бесконечный цикл не повесит игру — приложение остановится с ошибкой.

Серверная часть работает на сервере и делает только то, что настроил админ этого сервера.

## Скрипты (Lua)

Скрипт — это код на языке **Lua** (тот же, что в модах ComputerCraft/OpenComputers и в Roblox). Он рисует экран
сам, реагирует на мышь и клавиши, работает 20 раз в секунду — поэтому на нём можно сделать что угодно: игру,
калькулятор посложнее, чат со своим сайтом, игру по сети.

Готовые примеры — в папке мода `docs/examples/scripts/`:

* `snake` — «Змейка»: экран набок и во весь экран, клавиши, звуки, рекорд в хранилище;
* `tictactoe` — «Крестики-нолики онлайн» с другим игроком на сервере (так же делается «Дурак онлайн»);
* `weather-web` — настоящая погода с сайта (пример своего сайта или API);
* `doom` — 3D-шутер: бесконечные случайные уровни (комнаты, коридоры, ящики, лава) в семи локациях, пять монстров,
  шесть видов оружия, карта (пример `g3d`; текстуры — `textures/*.png`, нарисованы скриптом `tools/gen_doom.py`);
* `racing` — «Блочные гонки»: 3D-гонки с камерой за машинкой, боты, три трассы; **режим экрана** — игра на экране в
  мире, друзья подключаются к лобби, экран делится на окна игроков, телефон — джойстик (графика — `tools/gen_racing.py`);
* `blockstrike` — «Block Strike», командный шутер по мотивам CS по сети: закладка бомбы, раунды, покупка, 13 видов
  оружия, гранаты, 4 карты, боты на свободных местах. Пример большой игры из нескольких файлов (`require`), игры по сети
  через хоста (`net`, с учётом лимита сообщений), попаданий через `g3d.pick`, оружия от первого лица в 3D (`viewmodel.lua`)
  и своих звуков `sounds/*.wav` (графика — `tools/gen_strike.py`, звуки — `tools/gen_strike_sounds.py`).

Выложить свои приложения в «Магазин» телефона — docs/APP_STORE.md.

Скопируйте папку примера в `blockphone/apps/` — приложение появится на рабочем столе.

### Первая программа

`blockphone/apps/hello/app.json`:

```json
{"id": "hello", "name": "Привет", "script": "main.lua"}
```

`blockphone/apps/hello/main.lua`:

```lua
local clicks = 0

function onDraw(dt)                       -- каждый кадр
  gfx.clear(theme.background())
  gfx.textCenter("Нажато: " .. clicks, screen.width() / 2, 40, theme.text(), 1.5)
  if ui.button(30, 80, 100, 20, "Нажми", "primary") then
    clicks = clicks + 1
  end
end
```

Сохраните — телефон перечитает файлы за пару секунд. Ошибка в коде видна прямо в приложении (с номером строки)
и кнопкой «Перезапустить».

### Файлы приложения

* Все `*.lua` в папке приложения (и в подпапках) — код. Главный — из `"script"`. Другие подключаются через
  `require("cards")` → `cards.lua`, `require("lib.util")` → `lib/util.lua`.
* Все `*.png` (кроме `icon.png`) — картинки для `gfx.image("img/card.png", ...)`, кнопок и 3D; `*.obj` — 3D-модели. Пиксели не размываются — удобно
  для пиксель-арта.
* Пределы: до 128 файлов кода (каждый до 512 КБ, всего 2 МБ), до 1024 картинок, моделей и звуков (картинка/модель — до 2 МБ,
  звук — до 4 МБ, всего 48 МБ); в магазине — до 1200 файлов в архиве.

### Что вызывает телефон (объявите нужные функции)

### Рисование — `gfx` (в `onDraw`)

Координаты — в точках экрана приложения: `screen.width()` × `screen.height()` (обычно 160 × ~290; набок — шире).
Цвет — `"#RRGGBB"`, `"#AARRGGBB"` или число `0xAARRGGBB`; цвета темы телефона — `theme.accent()`, `theme.text()`,
`theme.secondary()`, `theme.background()`, `theme.card()`, `theme.danger()`, `theme.onAccent()`, `theme.dark()`.

|---|---|
| `gfx.clear(color)` | залить весь экран |

| `gfx.roundRect(x, y, w, h, r, color)`, `gfx.circle(cx, cy, r, color)` | скруглённый / круг |
| `gfx.gradient(x, y, w, h, top, bottom)` | вертикальный градиент |
| `gfx.line(x1, y1, x2, y2, color[, thickness])` | линия |
| `gfx.panel(x, y, w, h)` | карточка в стиле телефона |
| `gfx.text(s, x, y[, color[, scale[, shadow]]])`, `gfx.textCenter(s, cx, y, ...)` | текст |
| `gfx.textWidth(s[, scale])`, `gfx.wrap(s, maxWidth[, scale])` | ширина текста; перенос по словам → таблица строк |

### Свои картинки для интерфейса

Любые `*.png` из папки приложения: `gfx.image(...)`, `gfx.nine(path, x, y, w, h, border[, tint])` — картинка «девяткой»
(углы `border` пикселей не растягиваются: удобно для кнопок и рамок любого размера),
`ui.imageButton(x, y, w, h, normal[, hover[, text[, textColor[, border]]]])` — кнопка из своих картинок (обычная и при
наведении), возвращает `true` при нажатии.

### 3D — `g3d` (игры от первого лица, гонки, что угодно)

Телефон рисует 3D сам (без видеокарты игры, на всех ядрах процессора): треугольники с текстурой и перспективой,
мипмапы (вдали текстура не рябит) и по желанию сглаживание, буфер глубины, цветной свет (окружающий + солнце, по граням
или по нормалям вершин), точечные источники (вспышки, взрывы, лампы), туман, небо с солнцем, прозрачность «вырезом»
(альфа < 50 %), смешиванием и сложением (свечение). Для уровня — **статическая сцена**: она рисуется кусками (только
видимое), для неё можно **запечь свет** (тени от солнца, тёмные углы и тоннели, лампы) и в ней работают **лучи** и
**столкновения** — уровни любой формы (пандусы, лестницы, наклонные стены), а не только сетка клеток.
Мир: **Y — вверх**, yaw 0 смотрит вдоль +Z, yaw 90 — вдоль +X.

| Функция | Что делает |
|---|---|
| `g3d.texture("tex/wall.png"[, {filter = "linear", mipmap = false}])` | текстура из папки приложения → номер. По умолчанию — чёткие пиксели с мипмапами; `filter = "linear"` — сглаживание |
| `g3d.box(w, h, d[, uvScale])`, `g3d.plane(w, d[, uvScale])` | готовые модели (uvScale — повторов текстуры на метр) |
| `g3d.mesh{vertices = {x,y,z,u,v, ...}, indices = {1,2,3, ...}, normals = {nx,ny,nz, ...}}` | своя модель (индексы с 1; без indices — каждые 3 вершины; normals — плавный свет, по 3 числа на вершину) |
| `g3d.obj("models/gun.obj")` | модель из файла OBJ (Blender: File → Export → Wavefront, с UV и нормалями, треугольники) |
| `g3d.camera(x, y, z, yaw, pitch[, fov])` | камера (углы в градусах) |
| `g3d.light(dx, dy, dz[, ambient[, {sun = color, ambient = color}]])` | направление лучей солнца; яркость окружающего света 0–1 (или цвета солнца и окружающего света) |
| `g3d.fog(color, near, far)` / `g3d.fog(nil)` | туман |
| `g3d.sky{top = color, horizon = color, bottom = color, sun = true, sunColor = color}` / `g3d.sky(nil)` | небо-градиент с солнцем (по направлению `g3d.light`) вместо заливки |
| `g3d.begin(x, y, w, h[, clearColor[, quality]])` | начать кадр в прямоугольнике экрана (в `onDraw`); quality 0.2–1 |
| `g3d.pointLight(x, y, z, color[, radius[, power]])` | точечный источник на этот кадр (до 16) — вызывать **до** рисования того, что он освещает |
| `g3d.draw(model, x, y, z[, {yaw, pitch, roll, scale, sx, sy, sz, texture, tint, lit, cull, id, pick, blend, probe}])` | нарисовать модель. `pick = false` — не мешает `g3d.pick`; `blend = "alpha"` — полупрозрачная, `"add"` — светится; в запечённой сцене модель сама темнеет в тени и тоннелях (`probe = false` — не темнеть) |
| `g3d.sprite(texture, x, y, z, w, h[, {tint, id, pick, blend}])` | картинка, всегда повёрнутая к камере (враги, предметы, вспышки); `pick = false` — видна, но `g3d.pick` смотрит сквозь неё (дым, листва) |
| `g3d.free(model)` | освободить модель (например, при смене уровня — вернуть лимит вершин) |
| `g3d.finish()` | вывести кадр (после — можно рисовать интерфейс `gfx` поверх) |
| `g3d.pick(sx, sy)` | что видно в точке экрана: `id` объекта (из `draw`/`sprite`) и расстояние — для выстрелов |
| `g3d.project(x, y, z)` | точка мира → экран (x, y, расстояние) или nil |
| `g3d.forward(yaw[, pitch])`, `g3d.right(yaw)` | направления (для ходьбы) |
| `g3d.stats()` | треугольников в кадре, ширина и высота кадра, время растеризации (мс), число потоков |

**Уровень (статическая сцена):**

| Функция | Что делает |
|---|---|
| `g3d.static(model, x, y, z[, {yaw, pitch, roll, scale, sx, sy, sz, texture, tint, lit, cull, id, solid}])` | добавить модель в уровень (один раз, не каждый кадр). `solid = false` — сквозь неё ходят и стреляют (надписи, трава) |
| `g3d.drawStatic()` | нарисовать уровень в кадре (вместо `g3d.draw` для каждой стены) |
| `g3d.clearStatic()` | очистить уровень (новая карта) |
| `g3d.bake{sun = {dx, dy, dz}, sunColor, sunPower, skyColor, skyPower, bounce, minLight, ao, density, rays, lamps = {{x, y, z, color = …, radius = …, power = …}, …}}` | запечь свет уровня в фоне: тени от солнца, окружающий свет только с открытого неба (под крышей темнее, `ao` — на сколько метров искать укрытие), отражённый свет `bounce`, лампы с тенями. Все поля необязательны |
| `g3d.bakeProgress()` | 0…1 — сколько готово (пока не 1 — уровень рисуется обычным светом) |
| `g3d.lightAt(x, y, z)` | насколько светло в точке (0…1) — например, чтобы враг в тени был хуже виден |
| `g3d.raycast(x, y, z, dx, dy, dz[, max])` | луч по твёрдым частям уровня: расстояние, нормаль (nx, ny, nz), `id` — или nil |
| `g3d.move(x, y, z, dx, dy, dz[, {radius = 0.3, height = 1.8, step = 0.35}])` | сдвинуть персонажа (x, y, z — ноги) с учётом стен: скользит вдоль стен, сам поднимается на ступеньки до `step`, не съезжает с пологих склонов. Возвращает x, y, z, стоит ли на земле, упёрся ли в потолок, в стену |

Пример движения с гравитацией: `vy = onGround and 0 or vy - 20 * dt` → `x, y, z, onGround = g3d.move(x, y, z, mx * dt, vy * dt, mz * dt)`.

Кадр считается в разрешении экрана (до ~640 тыс. пикселей) на всех ядрах — тысячи треугольников в кадре идут плавно.
Пределы: 2000 моделей и 400 тыс. вершин на приложение, 300 тыс. треугольников в уровне. Примеры —
`docs/examples/scripts/doom/main.lua` (простой) и `docs/examples/scripts/blockstrike/render.lua` (уровень, запечённый
свет, вспышки).

**Обзор мышью:** `input.lockMouse(true)` — курсор прячется, движение мыши приходит в `input.mouseDelta()` (dx, dy с
прошлого вызова) и `onMouseMove(dx, dy)`; клики — в центр экрана. Esc отпускает мышь (вызывается `onMouseUnlock()`),
закрытие телефона — тоже.

### Кнопки и поля — `ui` (в `onDraw`)

* `ui.button(x, y, w, h, text[, style])` — рисует кнопку и возвращает `true` в кадре, когда по ней нажали. Стили:
  `"normal"`, `"primary"`, `"danger"`, `"selected"`. Так просто делаются меню: `if ui.button(...) then ... end`.
* `ui.hovered(x, y, w, h)` — мышь над прямоугольником.
* `ui.input(id, x, y, w, h[, placeholder[, multiline]])` — поле ввода, возвращает текст. `ui.setText(id, text)`,
  `ui.getText(id)`, `ui.focus(id)`.

### Экран, ввод, время

* `screen.width()`, `screen.height()`; `screen.landscape(true)` — повернуть телефон набок (`false` — обратно);
  `screen.fullscreen(true)` — во весь экран; `screen.title("…")` — заголовок; `screen.close()` — на рабочий стол.
* `screen.captureKeys(true)` — все клавиши — приложению (для игр: WASD не двигает игрока в режиме «на ходу», клавиша
  телефона не закрывает его). Esc всё равно работает как «назад».
* `screen.minimizeKey(true)` — клавиша телефона сворачивает приложение, даже когда оно забирает клавиши (игра:
  свернуть, переключить песню, вернуться). Свернули — `onHide`, вернулись — `onShow`.
* `screen.background(true)` — `onTick` (и `onMessage`) продолжаются при закрытом телефоне: хост сетевой игры считает
  матч, пока игрок свернул игру. Рисования (`onDraw`) в фоне нет; `input.down` в фоне — всегда false.
* `input.down("w")` — зажата ли клавиша прямо сейчас (`"mouse1"`, `"mouse2"` — кнопки мыши); `input.mouse()` — x, y.
* `time.now()` — миллисекунды, `time.clock()` — секунды с запуска, `time.date("HH:mm")` — строка даты/времени.
* `timer.after(seconds, fn)`, `timer.every(seconds, fn)` → id; `timer.cancel(id)` (таймеры идут, пока приложение открыто).

### Данные и прочее

* `storage.get(key[, default])`, `storage.set(key, value)` — своё хранилище (`storage`); значения — числа, строки,
  таблицы.
* `json.encode(value)`, `json.decode(text)`.
* `toast(text)` — всплывающее сообщение внизу экрана.
* `sound.play(name[, volume[, pitch]])` — звуки интерфейса: `ui.*`, `block.note_block.*`, `entity.experience_orb.pickup`,
  `entity.player.levelup` и некоторые другие, а также шаги и падение на блоки: `block.<блок>.step`, `block.<блок>.fall`
  (`block.stone.step`, `block.sand.step`, `block.grass.step`, `block.wood.step`, `block.metal.step`, `block.snow.step`…).
* **Свои звуки:** положите `*.ogg`, `*.wav` или `*.mp3` в папку приложения (можно в подпапку, до 4 МБ на файл, вместе с
  картинками — до 16 МБ). `sound.play("sounds/jump.ogg"[, volume])` — сыграть один раз, `sound.loop("music.ogg"[, volume])` —
  по кругу; обе возвращают номер звука, `sound.stop(номер)` — остановить, `sound.stop()` — все. Одновременно — до 32 звуков
  (их сводит общий микшер: без перегрузки, остановка — плавная, без щелчка; если звучит слишком громко, общий звук
  мягко приглушается); громкость — «Громкость звуков» телефона × `volume` (0..1). Когда приложение закрывают, его звуки замолкают.
* **Объёмный звук:** `sound.play(name, volume, pitch, pan[, muffle])` — `pan` от −1 (слева) до 1 (справа), `muffle` 0..1 —
  «за стеной» (глуше и тише), `pitch` 0.5..2 — высота тона (и для своих файлов). Так в игре слышно, откуда стреляют и где
  ходят. `sound.place(номер, pan[, muffle])` — подвинуть уже играющий свой звук. `sound.tune(номер, громкость, высота)` — плавно поменять громкость (множитель 0..2)
  и высоту тона (0.25..4) играющего своего звука: мотор, ветер, сирена (пример — `racing/audio.lua`). Ванильные звуки (шаги) с `pan` звучат
  через объёмный звук игры.
* `clipboard.set(text)` (`clipboard`), `openUrl(url)` (`links`), `runCommand("spawn")` (`commands`) — с подтверждением.
* `app.id`, `app.version`, `app.player` (свой ник), `app.lang`. `print(...)` пишет в лог игры.

### Настоящий браузер — `web` (разрешение `browser`)

Chromium внутри телефона: любые сайты, вход в аккаунты, видео (YouTube и т. п.). При первом открытии у игрока
скачивается Chromium (~140 МБ, один раз, в `blockphone/browser/jcef`); cookies и входы хранятся в общем профиле
`blockphone/browser/profile`. Видео с защитой (Netflix, Кинопоиск и т. п.) и видео в H.264 (Twitch) не показываются.
Готовый пример — `docs/examples/scripts/browser` («Браузер»).

* `web.start()` — начать скачивание/запуск заранее; `web.status()` → `состояние, ход, ошибка`: `"downloading"`
  (ход 0..1 или −1), `"extracting"`, `"starting"`, `"ready"`, `"failed"`.
* `web.open(url)` → номер вкладки (до 4). Адрес без схемы дополняется `https://`, текст с пробелами — поиск Google.
  Открываются только адреса `http://` и `https://` (`javascript:`, `file:`, `chrome:` и прочие — пустая страница).
* `web.draw(tab, x, y, w, h[, zoom])` — показать вкладку (только в `onDraw`). Чёткость — по реальным пикселям экрана;
  `zoom` > 1 — страница крупнее. Нажатия, колесо, движение мыши и клавиши (после нажатия на страницу) телефон
  передаёт странице сам — `onClick`/`onKey` скрипта при этом не вызываются.
* `web.go(tab, url)`, `web.back(tab)`, `web.forward(tab)`, `web.reload(tab)`, `web.stop(tab)`, `web.close(tab)`,
  `web.focus(tab[, true/false])`.
* `web.info(tab)` → `{url, title, loading, canBack, canForward, ready, focused}`.
* Esc / «назад» телефона по-прежнему вызывают `onBack` скрипта (браузер-пример листает историю назад).

### Свой сайт — `http` (разрешение `internet`)

```json
"permissions": ["internet"], "hosts": ["api.mysite.ru"]
```

```lua
http.get("https://api.mysite.ru/top", function(ok, status, body)
  if ok then top = json.decode(body) end
end)
http.post("https://api.mysite.ru/score", {player = app.player, score = 10}, function(ok, status, body) end)
```

Только сайты из `"hosts"`; таблица в `post` отправляется как JSON; свои заголовки — последним параметром (например,
ключ вашего API). Перенаправления не выполняются, cookies не отправляются.

### Фото, голос, уведомления, работа в фоне

* **Фото** (`photos`): `photos.pick(function(photo) … end)` — поверх приложения открывается галерея, игрок выбирает фото
  (или закрывает — тогда `photo` = nil). `photo` — «ручка» `{photo = n}`: `photos.draw(photo, x, y, w, h[, "cover"|"fit"])` в
  `onDraw` показывает его, `http.upload(url, photo, {maxSide = 1280, maxBytes = 600000, headers = {…}}, function(ok, status, body) end)`
  отправляет JPEG (заголовки `Content-Type: image/jpeg`, `X-Width`, `X-Height`).
  Стикер из фото: `photos.sticker(photo, {shape = "rounded"|"circle"|"square", outline = true, zoom = 1..4, x = -1..1,
  y = -1..1, size = 32..512}, function(sticker, err) end)` — квадрат (сдвиг x/y, приближение zoom), форма с прозрачным
  фоном и белой обводкой; собирается в фоне (новый вызов, пока прошлый не готов, заменяет его — удобно для предпросмотра
  при перетаскивании). `sticker = {sticker = n, size}`: `photos.drawSticker(sticker, x, y, w, h)`, отправить —
  `http.upload(url, sticker, {maxBytes = 262144, headers = …}, cb)` (PNG, `Content-Type: image/png`, `X-Width`, `X-Height`);
  `photos.forget(sticker)` — освободить.
* **Картинки с сайта** (`internet`): `gfx.urlImage(url, x, y, w, h[, "cover"|"fit"])` — рисует, когда скачается (возвращает
  true); `images.size(url)` → ширина, высота; `images.failed(url)` — не скачалась. Только сайты из `"hosts"`, до 4 МБ.
* **Голос** (`microphone`): `mic.start(секунды)` (до 300), `mic.recording()`, `mic.time()` (мс), `mic.level()` (0..1),
  `mic.error()`, `mic.cancel()`, `mic.stop(function(clip, err) end)` → `clip = {clip = n, duration = мс}` (OGG Opus 16 кГц);
  отправить — `http.upload(url, clip, {headers = …}, cb)` (`Content-Type: audio/ogg`, `X-Duration-Ms`).
  Проигрывание голосовых: `audio.play(url или clip)` (повторно — пауза), `audio.state(url)` → "loading" | "playing" | "paused"
  | "idle" | "error", `audio.progress(url)` 0..1, `audio.stop()`, `audio.volume([v])` — усиление голосовых этого
  приложения 0..5 (1 — как записано; громче — мягкий ограничитель, без хрипа), возвращает текущее.
* **Уведомления** (`notifications`): `notify(заголовок, текст[, метка])` — звук, всплывающее окно и центр уведомлений;
  нажатие открывает приложение и вызывает `onNotification(метка)`; `unnotify(метка)` — убрать.
* **Фон** (`background`): приложение запускается вместе с игрой (даже если его не открывали) и живёт при смене миров —
  так делаются мессенджеры и напоминания. `onTick` идёт всегда, `onDraw` — только когда приложение на экране.
* **Хранилище** (`storage`) сохраняется на диск само (через секунду после изменения и при сворачивании/выходе из игры);
  одно значение — до 16 КБ, всё хранилище — до 64 КБ.

Пример — приложение клана `clan-app/` в репозитории мода (чаты со своим сервером, фото, голосовые, стикеры, уведомления).

### Режим экрана — `display` (разрешение `display`)

Приложение может показывать картинку **на экране в мире** (экраны из приложения «Экраны»): игра для компании, табло,
презентация, викторина. Владелец экрана выводит приложение на свой экран, друзья **подключаются через то же
приложение**, а клавиша джойстика (по умолчанию **G**) превращает телефон в геймпад: телефон в руках набок (это видно
другим), клавиши и мышь идут приложению. Пример — `docs/examples/scripts/racing` («Блочные гонки»).

**Как это устроено.** Картинку для экрана каждый игрок рисует **у себя** — в `onDisplay`, той же графикой `g3d`, что и в
телефоне. Поэтому игра должна быть одинаковой у всех: удобно, когда владелец экрана («ведущий») считает игру и
рассылает остальным состояние через `net` (разрешение `multiplayer`), а остальные шлют ему свои кнопки. Кто не
подключился (или у кого приложения нет), видит на экране заставку: название приложения и подсказку, как подключиться.

| Функция | Что делает |
|---|---|
| `display.screens()` | свои экраны игрока: таблица `{owner, id, name, mine, width, height (в блоках), app, distance}` |
| `display.nearby([радиус])` | экраны рядом (до 64 блоков), на которых сейчас **это** приложение, — к ним можно подключиться |
| `display.start(id[, {w = 384, h = …}])` | вывести приложение на свой экран `id` (вы — ведущий). Размер кадра в пикселях: по ширине `w`, высота — по пропорциям экрана (до 960 × 720). Возвращает `true` или `false, ошибка` |
| `display.join(owner, id[, {w, h}])` | подключиться к экрану игрока `owner`, на котором это приложение |
| `display.stop()` | отключиться; ведущий заодно убирает приложение со своего экрана |
| `display.current()` | экран, к которому подключено приложение: `{owner, id, name, host, w, h, …}` или `nil` (экран пропал, приложение на нём сменили) |
| `display.size()` | ширина и высота кадра |
| `display.control(true[, подсказка])` | режим джойстика: телефон закрывается, в руках — набок двумя руками, клавиши и мышь — приложению (`input.down`), внизу подсказка. `display.control(false)` — выйти. Игрок выходит и сам — клавишей джойстика или Esc |
| `display.controlling()` | игрок сейчас управляет вашим экраном |

**Рисование кадра** — только в `onDisplay(dt, w, h)` (до 30 раз в секунду, пока приложение подключено к экрану):

| Функция | Что делает |
|---|---|
| `g3d.begin(x, y, w, h[, фон[, качество]])` … `g3d.finish()` | 3D, как в телефоне, но координаты — пиксели кадра. Можно несколько раз за кадр: **окна игроков** (экран пополам — два `begin/finish` рядом) |
| `display.clear(color)` | залить кадр |
| `display.rect(x, y, w, h, color)` | прямоугольник (с прозрачностью `#AARRGGBB`) |
| `display.image(path, x, y[, w, h[, {alpha}]])` | картинка PNG из папки приложения |
| `display.text(s, x, y[, {size = 10, color, align = "left"/"center"/"right", shadow = true}])` | надпись шрифтом игры (кириллица есть), `size` — высота в пикселях кадра; рисуется поверх картинки |
| `display.textWidth(s[, size])` | ширина надписи |

`gfx.*` и `ui.*` в `onDisplay` не работают (они рисуют в телефон), а `display.*`-рисование — только в `onDisplay`.

**Пока приложение подключено к экрану, оно работает и с закрытым телефоном**: идут `onTick`, `onMessage` и `onDisplay`
(ведущий продолжает игру, когда игрок взял телефон-джойстик). Выход из мира отключает приложение от экрана.

**Как игрок начинает:**

* из приложения: ваша кнопка «Режим на экране» → `display.screens()` → `display.start(id)`;
* из меню экрана: «Экраны» → экран → «Прилож.» → ваше приложение — телефон откроет его и вызовет
  `onDisplayInvite(owner, id, true)`;
* друг подключается: в вашем приложении — список `display.nearby()` → `display.join(owner, id)`; или подходит к экрану и
  жмёт **G** — его телефон откроет приложение и вызовет `onDisplayInvite(owner, id, false)`.

Минимальный пример (общий счётчик нажатий на экране):

```lua
local count, host = 0, false

function onDisplayInvite(owner, id, mine)
  if mine then host = display.start(id) else display.join(owner, id) end
end

function onDisplay(dt, w, h)
  display.clear("#101828")
  display.text("Нажатий: " .. count, w / 2, h / 2 - 10, {size = 20, align = "center"})
end

function onTick()
  if display.controlling() and input.down("space") then
    if host then count = count + 1; net.broadcast({c = count})
    else net.send(display.current().owner, {press = true}) end
  end
end

function onMessage(from, d)
  if host and d.press then count = count + 1; net.broadcast({c = count}) end
  if not host and d.c then count = d.c end
end

function onDraw()
  gfx.clear(theme.background())
  local cur = display.current()
  gfx.text(cur and ("На экране: " .. cur.name) or "Выберите приложение в меню экрана", 8, 8, theme.text())
  if cur and ui.button(8, 30, 140, 20, "Джойстик", "primary") then display.control(true, "Пробел — нажать") end
end
```

app.json: `"permissions": ["display", "multiplayer"]`. Советы: кадр 384 × 216 хватает (3D на всех ядрах процессора;
больше — дольше); сеть — 4–5 снимков в секунду через плагин (`net.mode() == "cloud"` — можно 10), между снимками двигайте
объекты плавно; надписи делайте через `display.text` — они чёткие на любом размере экрана.

### Игры по сети — `net` (разрешение `multiplayer`)

* `net.players(function(names) ... end)` — кто сейчас на сервере с BlockPhone (кроме вас);
* `net.send(name, data)` — сообщение этому же приложению у игрока `name`; `net.broadcast(data)` — всем;
* `onMessage(from, data)` — пришло сообщение (`data` — то, что отправили: число, строка, таблица);
* `net.online()` — можно ли играть по сети (плагин BlockPhone на сервере или облачная комната);
* `net.mode()` — как идёт связь: `"plugin"`, `"cloud"`, `"connecting"`, `"taken"` (ваш ник уже занят в облачной
  комнате), `"none"`.

**Без плагина на сервере** телефон сам подключается к облачной комнате BlockPhone: все с модом на одном сервере Minecraft
(вошедшие по одному адресу) видят друг друга так же, как с плагином, — менять приложение не нужно. Ещё есть комнаты по
коду — играть с разных серверов и из одиночной игры: `net.newCode()` → код (и войти в комнату), `net.joinCode(код)` →
true/false, `net.code()` → код или nil, `net.leaveCode()`. Пока выбрана комната по коду, `net.*` идёт через неё (и при
плагине). До 8 КБ на сообщение; через плагин — 40 сообщений за 5 с, через облако — 100 (`net.mode() == "cloud"` — можно
слать чаще).

Сервер ничего не разбирает — только пересылает. Удобная схема для карточных и настольных игр: тот, кто пригласил,
ведёт игру (тасует колоду, проверяет ходы) и рассылает остальным состояние; остальные шлют ему свои ходы. Если
приложение у игрока закрыто, сообщения дождутся его открытия, а на телефон придёт уведомление.

#### Свой сервер для игры по сети (Cloudflare, бесплатно)

Без плагина на сервере сообщения `net.*` идут через облачный сервер комнат. По умолчанию это общий сервер BlockPhone,
но вы можете поднять **свой** — тогда онлайн вашего приложения не зависит ни от плагина, ни от сервера BlockPhone, а
лимиты и сам сервер — ваши. Готовый сервер мод кладёт в папку приложений: `blockphone/apps/relay-server-template/`
(`worker.js`, `wrangler.toml`, `README.md`; обновляется вместе с модом).

1. **Аккаунт Cloudflare.** Зарегистрируйтесь на https://dash.cloudflare.com — хватит бесплатного тарифа. В разделе
   «Workers & Pages» один раз выберите себе поддомен `workers.dev`.
2. **Node.js.** Установите LTS-версию с https://nodejs.org (вместе с ней ставится `npx`).
3. **Скопируйте папку** `relay-server-template` куда угодно (например, на рабочий стол) и откройте в ней терминал
   (в Проводнике: адресная строка → `cmd` → Enter).
4. **Имя сервера.** В `wrangler.toml` поменяйте `name = "my-blockphone-relay"` на своё (латиница, цифры, дефис).
5. **Вход:** `npx wrangler login` — откроется браузер, нажмите «Allow».
6. **Выкладка:** `npx wrangler deploy`. В конце будет адрес вида `https://<имя>.<поддомен>.workers.dev`.
   Проверка: откройте в браузере `https://<имя>.<поддомен>.workers.dev/status` — ответ `{"ok":true,"service":"blockphone-relay",…}`.
7. **app.json** вашего приложения:

```json
"permissions": ["multiplayer"],
"relay": "https://my-blockphone-relay.example.workers.dev"
```

Больше ничего менять не нужно: `net.send/broadcast/players/online/mode` и комнаты по коду (`net.newCode/joinCode`)
работают так же, только через ваш сервер. Если на сервере Minecraft стоит плагин BlockPhone, сообщения по-прежнему идут
через плагин (пока не выбрана комната по коду). Своему серверу приходят только сообщения вашего приложения, а ваше
приложение получает сообщения только с него.

Что умеет сервер: комнаты «этот сервер Minecraft» (по адресу сервера) и по коду, до 200 игроков в комнате, сообщение
до 8 КБ, до 100 сообщений за 5 с от игрока (поменять — `RATE_COUNT` в `worker.js`), ничего не хранит; пока никто не
играет, подключения «спят» и почти ничего не стоят. Бесплатного тарифа Cloudflare (100 000 запросов к Durable Objects в
сутки; 20 сообщений WebSocket считаются за один запрос) хватает примерно на 10 часов в сутки игры 10 человек, которые
шлют по 10 сообщений в секунду. Обновить сервер — снова `npx wrangler deploy` с новым `worker.js`.

Проверка без выкладки: `npx wrangler dev --port 8797` в той же папке и `"relay": "http://127.0.0.1:8797"` в app.json
(http разрешён только для localhost/127.0.0.1; перед публикацией верните https-адрес).

### Серверная часть из скрипта (разрешение `server`)

`server.call("transfer", {to = "Alex", amount = "10"}, function(ok, toast, values) end)` — функция серверной части
(как кнопка с `"server"`); `server.vars(function(values) end)` — её переменные (страница `"script"`).

### Ограничения скрипта

Нет `io`, `os`, `load`, `dofile`, `debug`, `coroutine`, доступа к Java и файлам. Каждый вызов (`onDraw`, `onTick`,
обработчик…) может сделать ограниченное число шагов — бесконечный цикл остановит приложение с ошибкой «работал
слишком долго», игра не зависнет. `string.rep` — не больше 1 МБ.

## Серверная часть

Если приложению нужны данные сервера, админ кладёт серверную часть в папку `apps` BlockPhone на сервере:

* Paper: `plugins/BlockPhone/apps/<id>.json`
* Fabric: `config/blockphone/apps/<id>.json`
* Velocity / BungeeCord: `plugins/blockphone/apps/` или `plugins/BlockPhone/apps/` (команды — команды прокси)

`<id>` — тот же id, что у клиентского приложения. Файлы перечитываются каждые 5 секунд, перезапуск не нужен.

```json
{
  "id": "bank",
  "permission": "myserver.bank",
  "variables": {
    "balance": "%vault_eco_balance_formatted%",
    "rank": "%luckperms_primary_group_name%"
  },
  "functions": {
    "transfer": {
      "inputs": {
        "to": {"kind": "player", "required": true},
        "amount": {"kind": "number", "min": 1, "max": 1000000, "required": true}
      },
      "command": "pay {to} {amount}",
      "as": "player",
      "toast": "Отправлено {amount} игроку {to}",
      "error": "Перевод не выполнен",
      "then": "main"
    }
  }
}
```

* `permission` — право (LuckPerms и т. п.), без которого серверная часть игроку не отвечает. Пусто — всем.
* `variables` — переменные для страниц с `"server": true`. Можно писать `{player}`, `{uuid}`, `{online}` и
  плейсхолдеры PlaceholderAPI `%...%` (на Paper, если установлен PlaceholderAPI).
* `functions` — что делает действие `{"server": "transfer"}`:
  * `inputs` — **проверка полей на сервере** (сервер не доверяет телефону). Значения доступны как `{to}`, `{amount}`.
  * `command` / `commands` — команды; `"as": "player"` (по умолчанию, с правами игрока) или `"as": "console"`
    (от консоли — **осторожно**: подставляйте только проверенные поля `kind: number/player`). Для команд от консоли
    подставляются **только поля из `inputs`**; если в команде осталось неописанное поле `{имя}`, она не выполняется,
    а в лог сервера пишется предупреждение.
  * `toast`, `error` — сообщения игроку; `then` — куда перейти.
* После функции телефон получает свежие `variables` — баланс на экране обновится сам.
* Все команды из приложений пишутся в лог сервера: `[apps] Steve (bank.transfer): player /pay Alex 100`.

## Java-API для плагинов

Если логики больше, чем «выполнить команду», серверную часть пишут на Java. BlockPhone даёт класс
`dev.blockphone.common.apps.BlockPhoneApps` (он есть в jar-файле BlockPhone для Paper, Fabric, Velocity и BungeeCord):

```java
BlockPhoneApps.handler("bank", new BlockPhoneApps.AppHandler() {
    @Override
    public Map<String, String> variables(UUID player, String page) {
        return Map.of("balance", economy.format(economy.getBalance(Bukkit.getOfflinePlayer(player))));
    }

    @Override
    public AppResult call(UUID player, String function, Map<String, String> inputs) {
        if (!function.equals("transfer")) return null;          // не наша функция
        // ... перевод через Vault ...
        return AppResult.ok("Отправлено").then("main");          // или AppResult.error("Недостаточно денег")
    }
});
```

* Методы вызываются в главном потоке сервера.
* `AppResult.ok(текст)`, `AppResult.error(текст)`, `AppResult.open(страница)`, `.then(страница)`.
* Если у функции есть описание в `<id>.json` (`inputs`), Java получает уже проверенные значения; иначе — очищенные
  (без переводов строк и цветовых кодов), проверьте их сами.
* `BlockPhoneApps.register(json)` — серверная часть из кода (тот же JSON, что в файле).
* Подключение: `compileOnly files("BlockPhone-paper-<версия>.jar")`, в plugin.yml `depend: [BlockPhone]`.

Полный пример плагина — `docs/examples/bank-plugin/BankPhoneApp.java`.

## Блокировка приложений на сервере

Админ решает, какие приложения игроков работают на его сервере. Настройка `apps` в конфиге BlockPhone:

```yaml
apps:
  mode: blacklist          # blacklist — все, кроме списка; whitelist — только из списка; none — никакие
  blacklist: [tapper, "sha256:9f2c..."]
  whitelist: []
```

* Запись — **uid** приложения (`uid:bp…`, рекомендуется), id приложения (`snake` или `id:snake`) или хэш его `app.json`
  (`sha256:...`). uid уникален: у двух разных приложений с одинаковым id или названием (например, двух «Змеек» из разных
  каталогов) он разный, и он не меняется при обновлениях. uid видно в «Магазине» (внизу страницы приложения) и в
  «Настройки → Свои приложения» — нажатие копирует. Хэш блокирует конкретную версию файла.
* Запрещённое приложение на этом сервере не открывается («отключено на этом сервере»), а сервер не отвечает его
  серверной части. В одиночной игре и на других серверах оно работает как обычно.
* Fabric: `apps` в `config/blockphone/server.json`; Velocity/BungeeCord — `apps` в `config.json` плагина.

## Частые ошибки

Ошибки видны в «Настройки → Свои приложения» (у игрока) и в логе сервера (у серверной части).

| Ошибка | Что делать |
|---|---|
| `bad JSON` | Лишняя или пропущенная запятая/скобка. Проверьте файл на jsonlint.com. Сохраняйте в UTF-8. |
| `needs permission "..."` | Добавьте разрешение в `"permissions"`. |
| `opens unknown page` | Опечатка в id страницы в `open`/`then`. |
| `id must be ...` | id — только латиница в нижнем регистре, цифры, `_`, `-`. |
| `icon must be a PNG` | Иконка — PNG до 32 КБ. |
| `script "..." not found` | Имя в `"script"` не совпадает с файлом `.lua` в папке приложения. |
| `"internet" needs "hosts"` | Перечислите сайты в `"hosts"`. |
| `main.lua:12: attempt to ...` | Ошибка в коде: файл и номер строки — в начале сообщения. |
| «Скрипт работал слишком долго» | Бесконечный цикл или слишком тяжёлый расчёт в одном вызове. |
| «На этом сервере нет серверной части» | Админ не положил `<id>.json` в папку `apps` сервера или id не совпадает. |
| Переменная показывается как `{balance}` | Сервер её не прислал: проверьте `variables` и что у страницы `"server": true`. |
