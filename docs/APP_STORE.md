# Магазин приложений BlockPhone: как выложить свои приложения

В телефоне есть приложение **«Магазин»**. Оно показывает приложения из **источников** — это ссылки на файл
`catalog.json` (каталог). Каталог и архивы приложений можно бесплатно хранить на **GitHub** — платить за хостинг не
нужно. Игрок добавляет ссылку на ваш каталог в «Магазин → Источники» и ставит приложения в один клик.

## Что такое каталог

```
мой-каталог/
  catalog.json          ← список приложений (название, версия, описание, ссылка на архив, хэш)
  apps/
    snake.zip           ← архив приложения: app.json, main.lua, картинки…
    doom.zip
  icons/
    snake.png           ← иконка для магазина (необязательно)
```

## Шаг 1. Подготовьте приложения

Каждое приложение — папка с `app.json` (как в docs/CUSTOM_APPS.md). Положите все папки в одну:

```
мои-приложения/
  snake/   app.json  main.lua  icon.png
  doom/    app.json  main.lua  textures/…
```

Добавьте в `app.json` описание для магазина (необязательно, но так понятнее игрокам):

```json
"description": {"ru_ru": "Классическая змейка", "en_us": "Classic snake"}
```

И не забывайте `"version"` — по ней магазин понимает, что вышло обновление.

## Шаг 2. Соберите каталог

Нужен Python 3. В папке мода выполните:

```
python tools/make_catalog.py мои-приложения мой-каталог "Мои приложения"
```

Скрипт упакует каждое приложение в `apps/<id>.zip`, скопирует иконки в `icons/` и напишет `catalog.json` с размером и
хэшем SHA-256 каждого архива (по хэшу телефон проверяет, что файл не подменили и он скачался целиком).

Пример готового каталога — `docs/examples/store/` (собран из `docs/examples/scripts`).

## Шаг 3. Выложите на GitHub

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите **New repository**, имя, например, `blockphone-apps`, тип **Public**, создайте.
3. На странице репозитория: **Add file → Upload files**, перетащите **содержимое** папки `мой-каталог`
   (`catalog.json`, папки `apps` и `icons`), нажмите **Commit changes**.
4. Откройте `catalog.json` в репозитории и нажмите **Raw**. Ссылка в адресной строке — это и есть источник:

```
https://raw.githubusercontent.com/<ваш-ник>/blockphone-apps/main/catalog.json
```

Подойдёт любой хостинг, который отдаёт файлы по **https**: GitHub, GitLab, свой сайт, Яндекс Object Storage и т. п.
Ссылки на архивы и иконки в каталоге — относительные (`apps/snake.zip`), поэтому папки должны лежать рядом с
`catalog.json`.

## Шаг 4. Добавьте источник в телефоне

Телефон → **Магазин → Источники** → вставьте ссылку (Ctrl+V) → «+». Вкладка «Каталог» покажет приложения.
Нажмите **Установить** — телефон покажет разрешения приложения и спросит подтверждение. Источников можно добавить
несколько (свой, друга, сервера).

## Обновление приложения

1. Поменяйте код и увеличьте `"version"` в `app.json` (например, `1.0` → `1.1`).
2. Снова соберите каталог (`tools/make_catalog.py`) и загрузите на GitHub новые `catalog.json` и `apps/<id>.zip`.
3. В телефоне: «Магазин» → ⟳ (обновить) — у приложения появится кнопка **Обновить**.

Данные приложения (хранилище `storage`) при обновлении сохраняются.

## Формат catalog.json

```json
{
  "name": "Мои приложения",
  "apps": [
    {
      "id": "snake",
      "name": "Змейка",
      "version": "1.0",
      "author": "Вася",
      "description": "Классическая змейка",
      "permissions": ["storage"],
      "icon": "icons/snake.png",
      "download": "apps/snake.zip",
      "size": 2014,
      "sha256": "5d41…"
    }
  ]
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Как в `app.json`: латиница, цифры, `_`, `-` (магазин проверяет, что в архиве тот же id) |
| `download` | да | Ссылка на zip (относительно каталога или полная https) |
| `name`, `version`, `author`, `description` | нет | Для карточки в магазине |
| `permissions` | нет | Показываются перед установкой (сами права всё равно берутся из `app.json`) |
| `icon` | нет | PNG до 256 КБ |
| `sha256`, `size` | нет, но лучше указать | Проверка целостности архива |

## Безопасность

* Скачивание только по **https**; архив до 30 МБ; хэш сверяется с каталогом.
* Распаковываются только файлы приложения (`.json`, `.lua`, `.png`, `.obj`, `.txt`, `.md`, звуки `.ogg`, `.wav`, `.mp3`) и только внутрь папки
  приложения — исполняемые файлы и «выход» из папки (`../`) отбрасываются.
* `app.json` проверяется так же, как у приложений, положенных вручную; с ошибкой — не устанавливается.
* Приложение из магазина — такое же, как своё: песочница без доступа к миру, файлам, аккаунтам и переписке; команды и
  ссылки — только с подтверждением игрока. Сервер может запретить приложение по id или хэшу.

## Частые ошибки

| Ошибка | Что делать |
|---|---|
| `HTTP 404` | Ссылка неверная: откройте её в браузере. Нужна ссылка **Raw**, а не страница GitHub. |
| `only https:// links` | Источник и архивы — только https. |
| `checksum does not match` | Архив на сайте не совпадает с каталогом: пересоберите каталог и загрузите оба файла. |
| `app id is "x", catalog says "y"` | id в `app.json` и в каталоге должны совпадать. |
| `no app.json in the archive` | В zip должен быть `app.json` в корне (или в одной папке). |
