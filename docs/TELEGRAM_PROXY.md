# Telegram без VPN: прокси

Telegram в телефоне BlockPhone работает через TDLib, а TDLib умеет подключаться через прокси **MTProto**
(официальный прокси Telegram), **SOCKS5** и **HTTP**. Через прокси идёт всё: вход, переписка, фото, голосовые.
Игроку не нужен VPN — достаточно, чтобы был хотя бы один рабочий прокси.

## Как это работает в телефоне

«Настройки → Telegram → Прокси (без VPN)»:

| Режим | Что делает |
|---|---|
| **Авто** (по умолчанию) | Сначала напрямую. Если за 12 секунд не подключились — телефон проверяет «Мои прокси» и **общий список**, измеряет пинг каждого и включает самый быстрый. Перестал работать — ищет заново. |
| **Только мои** | Всегда через свои прокси (самый быстрый из рабочих). |
| **Выключен** | Напрямую. |

Свой прокси — вставьте ссылку в поле и нажмите «Добавить»:

* `tg://proxy?server=1.2.3.4&port=443&secret=ee...` или `https://t.me/proxy?server=...` — MTProto;
* `tg://socks?server=...&port=...&user=...&pass=...`, `socks5://user:pass@host:1080` — SOCKS5;
* `http://user:pass@host:8080` — HTTP.

Состояние подключения видно там же и на экране входа в Telegram («⇄ Через прокси … · 120 мс»).

## Общий список (для владельца мода)

Телефоны берут общий список из `proxies.json` в репозитории официального каталога
(`https://raw.githubusercontent.com/Jdhihfgiuahfgy/blockphone-apps/main/proxies.json`; GitHub в России открывается без VPN).
Список можно менять в любой момент — новая версия мода не нужна. Файл-образец — `store-repo/proxies.json`:

```json
{
  "proxies": [
    "tg://proxy?server=proxy.example.com&port=443&secret=ee0123...6578616d706c652e636f6d"
  ]
}
```

Публичные бесплатные прокси из интернета живут недолго и бывают небезопасны (их владелец видит, когда и с каких адресов
подключаются, хотя переписку прочитать не может — она зашифрована). Надёжнее поднять свой.

## Свой MTProto-прокси за 10 минут

Нужен любой VPS за пределами блокировок (от ~3 $ в месяц) с Docker.

```bash
# Секрет с маскировкой под обычный HTTPS (fake TLS) — его труднее заблокировать.
docker run --rm nineseconds/mtg:2 generate-secret --hex google.com
# Запуск на порту 443 (подставьте свой секрет).
docker run -d --restart=always --name mtg -p 443:3128 nineseconds/mtg:2 simple-run -n 1.1.1.1 -i prefer-ipv4 0.0.0.0:3128 <секрет>
```

Ссылка для телефона: `tg://proxy?server=<IP сервера>&port=443&secret=<секрет>`. Добавьте её в `proxies.json`
(для всех игроков) или раздайте игрокам, чтобы вставили в «Мои прокси».

Важно: прокси не обходит требования Telegram ко входу — ключи api_id/api_hash игрок всё так же берёт на my.telegram.org
(сайт тоже может требовать VPN; ключи нужны один раз).
